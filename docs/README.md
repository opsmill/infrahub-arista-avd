## Getting Started

1. **Setup**: `uv sync --all-packages`
2. **Start Services**: `inv start`
3. **Load Data**: `inv load`
4. **Run Generators**: Via Infrahub UI

See the main [CLAUDE.md](../CLAUDE.md) for command reference.
